# GitHub-ready project

This package contains the application source only. Replit/AI Studio templates, generated caches, local databases, git internals, and unrelated sandbox projects were excluded.

## Before running
1. Copy `.env.example` to `.env`.
2. Fill in your Firebase and Cloudinary values.
3. Never commit `.env`.
4. Run `npm install`.
5. Run `npm run dev`.

## GitHub
Create/clone the repository and push this folder. The included `.gitignore` prevents environment secrets, dependencies, build output, logs, and local databases from being committed.
